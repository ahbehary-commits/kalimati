# كلمتي – هيكل مشروع تطبيق نطق للأطفال (Flutter)

## التشغيل
```bash
flutter create kalimati
# انسخ مجلد lib/ وملف pubspec.yaml من هنا فوق الموجود
cd kalimati
flutter pub get
flutter run
```

## تدفق الشاشات
تعريفية (3 صفحات + اسم الطفل) ← رئيسية ← العوالم ← المستويات (مسار متعرّج بنجوم وأقفال) ← الأنشطة ← شاشة المكافأة (1–3 نجوم).

## ملفات مهمة
- `lib/data.dart`: العوالم والمستويات والأنشطة (محتوى تجريبي، غيّره بمحتواك).
- `lib/services.dart`: نقاط ربط التسجيل الصوتي وتشغيل الصوت (حاليا Stub).
- `lib/progress_store.dart`: حفظ النجوم والاشتراك على الجهاز.
- `lib/screens/activities.dart`: أنواع الأنشطة الثلاثة.

## المطلوب لاحقا
1. **التسجيل الصوتي**: أضف `record` و `permission_handler`، وصلاحية `RECORD_AUDIO` في AndroidManifest، ونفّذ `SpeechRecorder`.
2. **الأصوات**: أضف `audioplayers` وتسجيلات صوتية خاصة بك لكل كلمة وتعليمة.
3. **الصور والشخصية**: استبدل الإيموجي بصورك أنت (مرخّصة أو من تصميمك).
4. **الاشتراك**: `in_app_purchase` مع تحقق من الخادم بدل زر "تفعيل تجريبي".
5. **الخصوصية**: التطبيق يسجّل صوت أطفال، فجهّز سياسة خصوصية واضحة والتزم بسياسة Google Play للعائلات.
6. **المحتوى**: راجعه مع أخصائي نطق وتخاطب.

## الحصول على ملف APK
**بدون تثبيت أي شيء:** ارفع **محتويات** هذا المجلد (وليس المجلد نفسه) إلى جذر مستودع GitHub جديد (فرع main)، وتأكد أن مجلد `.github` ظاهر في الجذر. من تبويب Actions شغّل "Build APK"، وبعد دقائق نزّل الملف `kalimati-apk` من قسم Artifacts.

**على جهازك:** بعد تثبيت Flutter نفّذ `flutter build apk --release` وستجد الملف في `build/app/outputs/flutter-apk/app-release.apk`.

ملاحظة: هذا APK للتجربة. للنشر على Google Play تحتاج توقيعا خاصا بك (keystore) وبناء `appbundle`.
